# Level 1: Sales Performance Dashboard

## 1. Project Overview
The Sales Performance Dashboard analyzes retail sales data to help understand business performance, profitability, and product trends.

## 2. Objectives
- Analyze total sales and profit.
- Identify top-performing products.
- Understand monthly sales trends.
- Compare sales across categories and regions.
- Enable interactive data exploration.

## 3. Tools Used
- Microsoft Power BI
- Power Query for data preparation
- Superstore sales dataset

## 4. Data Preparation
The Superstore CSV dataset was imported into Power BI. Column data types were reviewed and adjusted, and the data was prepared for visualization.

## 5. Dashboard Components
The dashboard includes:
- Total Sales KPI
- Total Profit KPI
- Monthly Sales Trend
- Top-Selling Products
- Sales by Category
- Region, Category, and Month filters

## 6. Key Insights
The dashboard provides a way to compare sales and profitability, identify products contributing strongly to sales, and explore differences across categories, regions, and months. Specific conclusions should be based on the dashboard's displayed values and filters.

## 7. Conclusion
The project demonstrates how Power BI can transform retail sales data into an interactive dashboard for business performance analysis.

## 8. Deliverables
- Power BI dashboard (.pbix)
- Source dataset (.csv)
- Dashboard screenshot(s)
